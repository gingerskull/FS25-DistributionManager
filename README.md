# Distribution Manager for FS25

**Distribution Manager** adds a new **"Manager"** output mode to your production points in Farming Simulator 25. Instead of manually hauling products or letting them pile up, you can set up automatic pipelines that route outputs directly to other owned production facilities.

## What It Does

When a production output is set to **Manager** mode, the mod takes over and distributes the product to destinations you choose - no trailers, no pallets, no hassle.

### Distribution Modes

- **Auto Equalize** - Automatically balances fill levels across all enabled destinations. Products are sent where they are needed most, keeping everything in equilibrium.
- **Manual** - Set your own rules. Assign percentages or caps to each destination for precise control over where products go.

### Key Features

- **Smart Overflow Handling** - If all destinations are full, excess product stays safely in the source storage instead of disappearing.
- **Multi-Source Coordination** - Multiple production points can feed the same destination without conflicts. Everything coordinates naturally.
- **Works with Existing Mods** - Designed to coexist alongside other production mods like Production Revamp and ProductionStorageControl.
- **Multiplayer Ready** - Fully supported in multiplayer. All players see the same configuration and distribution rules.

## How to Use

### Setting Up a Distribution Rule

1. Open the **Productions** menu.
2. Select one of your owned production points.
3. In the outputs list, cycle the output mode until you see **Manager**.
4. A **"Configure Distribution"** button appears. Press it to open the settings dialog.
5. In the dialog:
   - Choose **Auto Equalize** or **Manual** mode.
   - Toggle destinations on or off. Only enabled destinations will receive product.
   - (Auto Equalize) Adjust the tolerance if desired.
   - (Manual) Set percentages or caps per destination.
6. Press **OK** to activate. Distribution begins immediately.

> **Tip:** The first time you switch an output to Manager, distribution does **not** start until you configure it.

### Changing or Stopping Distribution

- Cycle the output mode away from **Manager** to pause distribution. Your settings are saved and will resume instantly if you switch back.
- Re-open the **Configure Distribution** dialog anytime to add, remove, or adjust destinations.

## Installation

1. Download `FS25_DistributionManager.zip`.
2. Place the ZIP file in your FS25 `mods` folder.
3. Enable the mod in the game's mod selection screen.
